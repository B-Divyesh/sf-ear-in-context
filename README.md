# Ear in Context: an ear-training sandbox with voice-led progressions, sung-pitch keyboard, and no forced progression

Live: https://ear-in-context.sociobot.in — built by the Param Factory (`static-web`).

See `.factory/brief.json` for the researched problem this solves and `.factory/design.md` for the visual system.

## Develop

npm run dev
npm test
